# CreditFirst

**내 Claude Max 구독에 딸려 오는 API 크레딧을 먼저 쓰고, 모자랄 때만 돈 내는 API 키를 씁니다.**

- Claude Code에 붙이는 플러그인입니다. "Max 크레딧으로 API 키 만들어줘"라고 말하면 Claude가 Console(API 키를 관리하는 Anthropic 사이트, claude.ai와 다른 곳) 화면을 같이 넘기며 키를 만들고, 내 앱에 안전하게 넣어 줍니다. 브라우저 도구가 없으면 주소와 버튼 이름을 하나씩 알려 드려요.
- Max 계정이 여러 개이거나 서비스에 유료 키를 쓰고 있으면, **내 것인** 작은 허브(내 Vercel, 내 데이터베이스)를 띄워 크레딧부터, 초기화가 가까운 계정부터 쓰게 합니다.
- 오픈소스(MIT)입니다. **Anthropic과 관계없는 프로젝트입니다.**

[English README](README.md)

## 누구에게 맞나요

- Max 요금을 내고 있고, 딸려 오는 월 API 크레딧으로 내 스크립트나 앱을 돌리고 싶은 분
- 나나 우리 회사가 Max 계정을 여러 개 갖고 있어서, 주소 하나로 올바른 순서대로 쓰고 싶은 분
- 서비스가 유료 API 키로 돌고 있는데, 크레딧을 먼저 쓰게 하고 싶은 분

이런 용도는 아닙니다: 남과 크레딧을 모아 쓰기, API를 되팔기, claude.ai 로그인을 API처럼 쓰기. [약관 메모](docs/TERMS-NOTES.md)를 보세요.

## 설치 (Claude Code에서 두 줄)

```
/plugin marketplace add elon-choo/creditfirst
/plugin install creditfirst@creditfirst
```

## 준비물 (시작 전에)

- Claude Code
- Node 20 이상. 터미널에서 `node --version`으로 확인하세요. 없으면 https://nodejs.org 에서 설치합니다.
- 가입한 지 7일이 지난 Claude Max 구독 (7일이 지나야 API 크레딧 받기 버튼이 나와요)
- 허브를 만들 때만 (계정이 여러 개이거나 유료 키를 쓰는 서비스가 있을 때):
  - Vercel 계정, Vercel 프로그램 설치(`npm i -g vercel`), 로그인(`vercel login`)
  - 무료 Neon 데이터베이스. 설치 스크립트가 Vercel의 Neon 연동으로 만들어 주거나, Neon 주소를 복사해서 넣는 방법 중 고르면 됩니다.

## 비용과 시간

| | 비용 | 걸리는 시간 |
|---|---|---|
| Max API 크레딧 | Max 요금에 들어 있어요 | - |
| 허브 없이 (계정 1개, 유료 키 없음) | 추가 비용 없음 | 약 10분 |
| 허브 만들기 | Neon 무료 플랜 $0. Vercel 무료(Hobby) 플랜은 **개인·비상업 용도만** 됩니다. 회사·상업 서비스에 쓰는 허브라면 Vercel Pro가 필요해요. https://vercel.com/pricing 에서 지금 조건을 확인하세요. | 약 30~60분 |
| 유료로 넘어갈 때 | 크레딧이 모자라면 원래 쓰던 유료 키에서 돈이 나갑니다. `HUB_PAID_MONTHLY_CAP_USD`로 한 달 상한을 정해 두길 권해요. | - |
| 연결 시험 | 아주 작은 요청 한 번, 1센트도 안 되고 보통 크레딧에서 나가요 | 몇 초 |

## 처음 쓸 때

Claude Code에 이렇게 말하면 됩니다.

> Max 크레딧으로 API 키 만들어줘

(`/creditfirst:setup`을 쳐도 됩니다.) Claude가 먼저 묻습니다. Max 계정이 몇 개인지, 이미 배포한 서비스가 유료 API 키를 쓰고 있는지, 키를 쓸 프로젝트 폴더가 어디인지. 그다음 한 단계씩 안내합니다. 로그인은 내가 직접 하고, Claude는 구매·카드 등록·건너뛰기 버튼을 절대 누르지 않습니다.

Claude가 안내서 읽기나 스크립트 실행을 허락해 달라고 물으면 허락해 주세요. 이 스크립트들은 키 값을 화면에 보여 주지 않아요.

## 무엇이 만들어지나요

| Max 계정 | 서비스용 유료 키 | 결과 |
|---|---|---|
| 1개 | 없음 | (약 10분) 허브 없이 끝. 크레딧 키를 내 프로젝트 `.env`에 넣습니다. 크레딧이 떨어지면 돈이 나가지 않고 요청이 거절됩니다(그 조직, 즉 Console 안의 따로 된 지갑에는 카드가 없으니까요). 초기화되면 다시 됩니다. |
| 여러 개 | 상관없음 | (약 30~60분) 내 허브: 크레딧 계정부터(초기화가 가까운 순서), 모자랄 때만 유료 키 |
| 상관없음 | 있음 | 같은 허브. 절대 유료로 넘어가면 안 되는 앱은 "크레딧 전용" 키를 받습니다(크레딧이 없으면 402를 받고 앱이 자기 길로 갑니다). |

앱에서 바꿀 것은 두 줄입니다: `ANTHROPIC_BASE_URL`(내 허브 주소), `ANTHROPIC_API_KEY`(앱마다 따로 받는 허브 키).

## 키는 어디로 가나요 (안전 설계)

- **키가 놓이는 곳:** 내 프로젝트 `.env`(나만 읽을 수 있게, `.gitignore`에도 추가), 내 허브 데이터베이스(암호화해서 저장), 허브 비밀값은 내 컴퓨터 `~/.config/creditfirst/<허브이름>/`과 내 Vercel 설정. 우리 쪽으로 오는 것은 없습니다. 대신 맡아 주는 서비스가 아니에요.
- **직접 붙여 넣기가 가장 안전한 이유:** Claude가 읽은 것은 모두 Claude Code 대화 기록(`~/.claude/projects/…/*.jsonl`)에 남습니다. 내가 직접 `.env`에 붙여 넣거나, 허브를 쓸 때는 내 허브의 관리 화면(`/admin`)에 붙여 넣으면 Claude는 키를 보지 않습니다.
- **쉽고, 그래도 안전한 방법:** 키를 복사만 해 두면 Claude가 `scripts/put-key.mjs`를 돌려 클립보드에서 바로 파일로 옮깁니다. 키는 화면에 나오지 않고 끝 4글자만 보입니다.
- **꼭 원할 때만:** Claude가 키를 직접 읽게 할 수도 있습니다. 대화 기록에 남는다는 안내를 먼저 하고, 나중에 키를 새로 바꾸라고 알려 드립니다.
- 스크립트는 비밀값을 명령줄에 넣거나 출력하지 않습니다.

## 한계

- Vercel 허브는 4.5MB가 넘는 요청(큰 PDF·이미지)을 받지 못하고, 아주 긴 요청은 Vercel 요금제 시간 제한에 걸립니다.
- 메시지 보내기, 토큰 세기, 모델 목록만 받습니다. 대량 처리(Batch)·파일(Files) API는 안 됩니다.
- 허브가 보여 주는 남은 크레딧은 추정입니다. 진짜 숫자는 Console 결제 화면에 있습니다.
- Console 화면은 바뀔 수 있습니다. 안내서에서 우리가 직접 확인하지 못한 단계는 "미확인"으로 표시했습니다.
- v0.1은 Vercel + Postgres(Neon)만 지원합니다. Docker나 내 컴퓨터 전용 설치는 아직 없습니다.
