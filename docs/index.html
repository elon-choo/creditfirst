Max/Ultra 요금에 이미 들어 있는
API 크레딧, 그냥 버리고 계셨나요?

Claude Max(요즘은 Ultra로 표시돼요)를 쓰면 매달 API 크레딧이 같이 나와요. CreditFirst는 이 크레딧으로 API 키를 만들고, 내 앱에 안전하게 넣는 일까지 Claude Code가 대신 해 주게 합니다. 크레딧이 모자랄 때만 원래 쓰던 유료 키로 넘어가요.

① Max/Ultra 크레딧
② 유료 키
요청이 오면 크레딧부터 씁니다. 크레딧이 바닥났을 때만 유료 키에서 돈이 나가요.

시작은 세 단계면 끝나요

개발을 몰라도 괜찮아요. Claude가 묻는 말에 답하기만 하면 됩니다.

Claude Code에 두 줄을 붙여 넣으세요

한 줄씩 복사해서 Claude Code 입력창에 넣고 엔터를 누릅니다.

/plugin marketplace add elon-choo/creditfirst
/plugin install creditfirst@creditfirst

이렇게 말하세요

“Max/Ultra 크레딧으로 API 키 만들어줘”

또는 /creditfirst:setup을 입력해도 됩니다.

질문 세 개에 답하세요

Max/Ultra 계정이 몇 개인지, 이미 돌아가는 서비스가 유료 API 키를 쓰는지, 키를 넣을 프로젝트 폴더가 어디인지 묻습니다. 그다음은 Claude가 한 단계씩 같이 갑니다.

나는 어느 쪽일까요?

두 가지만 눌러 보세요. 무엇이 만들어지는지, 얼마나 걸리는지 바로 보여 드려요.

내가(또는 우리 회사가) 돈 내고 쓰는 Max/Ultra 계정은?
이미 배포한 서비스가 유료 Claude API 키를 쓰고 있나요?

허브 없이 끝나요 · 약 10분 · 추가 비용 없음

Max/Ultra 크레딧으로 만든 키를 내 프로젝트의 .env 파일에 넣으면 끝입니다.

  • 크레딧이 떨어지면 돈이 나가지 않고 요청이 멈춰요. 다음 달 크레딧이 들어오면 다시 됩니다.
  • 준비물: Claude Code, Node 20 이상, 가입 7일이 지난 Max/Ultra 구독

나만의 허브를 만들어요 · 약 30~60분

내 Vercel에 작은 중계 서버(허브)를 띄웁니다. 앱은 허브 주소 하나만 바라보고, 허브가 알아서 순서를 정해요.

  • Max/Ultra 크레딧부터 씁니다. 계정이 여러 개면 크레딧이 곧 초기화되는 계정부터 써요.
  • 크레딧이 모자랄 때만 유료 키로 넘어갑니다. 한 달 상한(HUB_PAID_MONTHLY_CAP_USD)을 걸어 두길 권해요.
  • 절대 유료로 넘어가면 안 되는 앱은 “크레딧 전용” 키를 받을 수 있어요.
  • 준비물: 위의 것 + Vercel 계정, 무료 Neon 데이터베이스(설치 중에 만들어 드려요)
  • 비용: Neon 무료. Vercel 무료(Hobby)는 개인·비상업 용도만 돼요. 회사 서비스용이면 Vercel Pro가 필요합니다.

키를 넘기는 방법은 세 가지예요

키는 돈과 같아요. Claude는 키를 만들기 전에 어떤 방법으로 받을지 먼저 묻고, 마지막 ‘만들기’와 ‘복사’ 버튼은 내가 직접 누릅니다.

더 안전덜 안전
가장 안전 · 추천

내가 직접 붙여 넣기

키를 복사해서 내 손으로 .env 파일에 붙여 넣어요. 허브를 쓰면 허브의 관리 화면(/admin)에 붙여 넣습니다. Claude는 키를 한 번도 보지 않아요.

쉽고 안전

복사만 하고 Claude에게 맡기기

키를 복사만 해 두면, Claude가 클립보드에서 바로 파일로 옮겨 넣어요. 키는 화면에 나오지 않고 끝 4글자만 보여 줍니다.

주의 · 꼭 원할 때만

Claude가 직접 키를 읽기

이 방법은 키가 Claude Code 대화 기록 파일에 그대로 남아요. 그래도 원하시면 Claude가 해 드리고, 끝난 뒤 키를 새로 바꾸라고 알려 드립니다.

자주 묻는 질문

제 요금제는 Max가 아니라 Ultra로 나와요. 써도 되나요?

네. 2026년 11월 초부터 claude.ai에서 Max 요금제가 Ultra로 표시돼요. CreditFirst는 둘을 같은 요금제로 다룹니다. “Ultra 크레딧으로 API 키 만들어줘”라고 말해도 똑같이 시작돼요.

Claude가 내 카드로 결제하거나 크레딧을 사지는 않나요?

안 해요. 크레딧 구매, 카드 등록, 건너뛰기 같은 버튼은 절대 누르지 않도록 되어 있어요. 로그인과 본인 확인도 내가 직접 합니다. 크레딧을 받는 조직(Console 안의 따로 된 지갑)에는 카드를 넣지 않기 때문에, 크레딧이 떨어지면 돈이 나가는 대신 요청이 멈춰요.

키는 어디에 저장되나요? 다른 데로 보내지지 않나요?

내 프로젝트의 .env(나만 읽을 수 있게 잠그고 .gitignore에도 추가), 허브를 쓰면 내 허브 데이터베이스(암호화)와 내 Vercel 설정에만 있어요. CreditFirst를 만든 쪽으로 오는 건 하나도 없습니다. 대신 맡아 주는 서비스가 아니라 전부 내 계정에서 돌아가요.

왜 직접 붙여 넣는 게 가장 안전한가요?

Claude가 화면이나 메시지로 읽은 내용은 Claude Code 대화 기록 파일(~/.claude/projects/…)에 남아요. 내가 직접 붙여 넣으면 키가 그 기록에 들어가지 않습니다.

Claude Code가 “허락해 주세요”라고 자꾸 물어요.

안내서를 읽거나 작은 스크립트를 실행할 때 물어보는 거예요. 허락해 주세요. 이 스크립트들은 키 값을 화면에 보여 주지 않습니다.

친구들과 크레딧을 모아 쓸 수 있나요?

안 됩니다. 내가(또는 우리 회사가) 돈 내고 쓰는 계정만 쓰는 도구예요. 크레딧을 남과 나누거나 API를 되파는 용도, claude.ai 로그인을 API처럼 쓰는 용도는 지원하지 않아요. 자세한 건 약관 메모를 보세요.

크레딧이 얼마나 남았는지 볼 수 있나요?

허브 화면에 추정치가 보여요. 정확한 숫자는 Console의 결제 화면에 있습니다.

안 되는 것도 있나요?

허브는 4.5MB가 넘는 요청(큰 PDF·이미지)을 받지 못하고, 메시지 보내기·토큰 세기·모델 목록만 지원해요. 대량 처리(Batch)와 파일(Files) API는 아직 안 됩니다. 지금은 Vercel + Neon 조합만 지원해요.

CreditFirst는 MIT 라이선스 오픈소스이고, Anthropic과 관계없는 프로젝트입니다. “Claude”와 “Anthropic”은 Anthropic의 상표입니다.
